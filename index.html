How it works

Pivots are found with a ZigZag swing filter, then checked against Elliott Wave rules (wave 2 can't retrace past the start of wave 1, wave 3 isn't the shortest, wave 4 doesn't overlap wave 1) and scored against typical Fibonacci ratios. This is a heuristic reading, not certainty — Elliott Wave counts are inherently open to more than one interpretation.

Educational tool only, not financial advice. Data via Binance public API, client-side, no backend required — deploy as-is on GitHub Pages.
